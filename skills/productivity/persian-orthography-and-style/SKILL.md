# دستور خط، نشانه‌گذاری و شیوه‌نامه جامع نگارش زبان فارسی

## ۱. اصول بنیادین و شیوه‌نامه کاراکترها (Character Normalization)

تمامی متون فارسی باید استاندارد یکپارچه یونیکد فارسی را رعایت کنند:
- **یکپارچه‌سازی ی و ک:** تبدیل قطعی «ي» عربی (U+064A) به «ی» فارسی (U+06CC) و «ك» عربی (U+0643) به «ک» فارسی (U+06A9).
- **تبدیل اعداد:** در متن فارسی از اعداد فارسی (`۰۱۲۳۴۵۶۷۸۹`) به جای ارقام انگلیسی استفاده شود.
- **تنوین و اعراب:** تنوین نصب همواره روی «الف» قرار می‌گیرد (مثلاً: `حتماً`، `واقعاً`، `طبيعتاً`، نه `حتمأ`). اعراب‌گذاری فقط در موارد تمایز معنایی کلمات هم‌نویسه (مانند `مَلِک` و `مِلک`، `کِشتی` و `کُشتی`) مجاز است.
- **تاء تأنیث:** تبدیل «ة» به «ت» یا «ه» بر اساس عرف زبان فارسی (`رحمت`، `صدمه`، `نظارت`).

## ۲. قواعد فاصله‌گذاری و نیم‌فاصله (Zero-Width Non-Joiner - ZWNJ)

نیم‌فاصله (کاراکتر `\u200c`) باید در تمامی موقعیت‌های زیر به دقت رعایت شود:

### الف) پیشوندهای فعلی
- پیشوندهای استمراری و نفی «می» و «نمی»:
  - ✅ `می‌روم`، `نمی‌دانست`، `می‌توانسته‌اند`، `می‌شنید`
  - ❌ `میروم`، `می روم`، `نمیدانست`، `نمی دانست`

### ب) نشانه‌های جمع
- نشانه‌های «ها»، «های»، «هایی»، «هایمان» و...:
  - ✅ `کتاب‌ها`، `خانه‌های`، `روش‌هایی`، `چشم‌هایش`
  - ❌ `کتابها`، `کتاب ها`، `خانه های`

### ج) صفت‌های تفضیلی و عالی
- پسوندهای «تر» و «ترین»:
  - ✅ `زیباتر`، `بزرگ‌ترین`، `آسان‌تر`
  - ⚠️ استثناهای پیوسته‌نویسی سنتی: `بهتر`، `مهتر`، `کهتر`، `بیشتر`، `کمتر`.

### د) ضمایر متصل و پی‌بست‌ها
- پس از کلمات مختوم به «ه» غیرملفوظ یا صامت‌های خاص:
  - ✅ `نامه‌اش`، `جامه‌ات`، `خانه‌مان`، `دست‌هایش`
  - ❌ `نامه اش`، `نامه اش`، `نامه ش`

### هـ) واژگان مرکب، مشتق و عطفی
- واژه‌هایی که یک مفهوم واحد تشکیل می‌دهند:
  - ✅ `گفت‌وگو`، `جست‌وجو`، `دست‌اندرکار`، `چوب‌کبریت`، `دانش‌آموز`، `پشت‌سرهم`، `هم‌زمان`، `بی‌صدا`، `دل‌نشین`، `پیش‌نویس`
  - ❌ `گفت و گو`، `گفتوگو`، `دست اندر کار`، `بی صدا`

## ۳. نشانه‌گذاری و علائم نگارشی (Punctuation Rules)

### ۱. قانون صفر خط‌تیره (Zero Em-Dash Rule)
- در نثر، داستان و ترجمه فارسی، کاربرد خط‌تیره کشیده (`—`)، خط‌تیره متوسط (`–`) یا خط تیره متصل برای شروع دیالوگ یا قطع کلام **اکیداً ممنوع** است.
- به جای خط‌تیره در دیالوگ‌ها، منحصراً از گیومه فارسی (`«...»`) استفاده می‌شود.
- به جای خط‌تیره برای جملات معترضه، از دو ویرگول (`، ... ،`) یا پرانتز `(...)` استفاده می‌شود.

### ۲. گیومه‌های فارسی (« »)
- تمامی دیالوگ‌ها، نقل‌قول‌های مستقیم، واژگان خاص و اصطلاحات ابداعی داخل `« »` قرار می‌گیرند.
- ❌ کاربرد گیومه‌های انگلیسی مانند `"..."` یا `“...”` مجاز نیست.

### ۳. فاصله‌گذاری علائم
- علائم `.` ، `،` ، `؛` ، `:` ، `!` ، `؟` باید بدون فاصله به کلمه پیش از خود بچسبند و با کلمه پس از خود یک فاصله سفید داشته باشند.
  - ✅ `هری به راهرو نگاه کرد، اما چیزی ندید.`
  - ❌ `هری به راهرو نگاه کرد ، اما چیزی ندید .`
- پرانتز و گیومه به متن درون خود می‌چسبند:
  - ✅ `«سلام!»` / `(هاگوارتز)`
  - ❌ `« سلام! »` / `( هاگوارتز )`

## ۴. ساختار استاندارد دیالوگ‌نویسی (Dialogue Attribution)

برای حفظ سلاست و دوری از سبک‌های تصنعی:

1. **اولویت با تقدم گوینده:**
   - ✅ `هری با تردید پرسید: «مطمئنی راه رو درست اومدیم؟»`
   - ✅ `اسنیپ با لحنی سرد گفت: «پاتر، به من نگاه کن.»`
2. **در صورت قرار گرفتن گوینده پس از دیالوگ:**
   - ✅ `«شاید حق با تو باشه»، ران این را گفت و چوبدستی‌اش را غلاف کرد.`
   - ❌ `«شاید حق با تو باشه.» — ران گفت.` (حذف کامل خط‌تیره)

## ۵. نشانه اضافه (Ezafe Marking)

- برای واژگان مختوم به «ه» غیرملفوظ، استفاده از همزه کوچک روی ه (`هٔ` یا `\u0654`) یا استفاده از نیم‌فاصله + ی استاندارد است:
  - ✅ `خانهٔ بزرگ` یا `خانه‌ی بزرگ`
  - ❌ `خانه ی بزرگ` (با فاصله کامل) یا `خانهء بزرگ`
- برای واژگان مختوم به مصوت‌های «الف» و «واو»، نشانه اضافه با «ی» نوشته می‌شود:
  - ✅ `صدای باد`، `موی سیاه`، `آب و هوای تازه`
  - ❌ `صداءِ باد`، `موءِ سیاه`

## ۶. پالایش گرته‌برداری و ترجمه‌زدگی (Anti-Calque & Idiomatic Persian)

| عبارت ترجمه‌زده و نامناسب | عبارت اصیل و روان فارسی |
| :--- | :--- |
| **توسط** معلم تنبیه شد | **معلم** او را تنبیه کرد |
| روی آن **کار می‌کند** | به آن **می‌پردازد** / آن را **انجام می‌دهد** |
| او **یک** کتاب جالب خواند | او کتاب جالبی خواند |
| او احساس **خستگی کرد** | احساس خستگی **به او دست داد** / **خسته شد** |
| **به عنوان یک** جادوگر | **در مقام** جادوگر / **به عنوان** جادوگر |
| به او **حمله برد** | به او **حمله کرد** / **تاخت** |
| دست به خودکشی زد | خودکشی کرد |
| مورد بررسی قرار داد | بررسی کرد |
| به مرحله اجرا درآمد | اجرا شد |

## ۷. اسکریپت پالایش و اعتبارسنجی خودکار (Regex Engine)

برای تصحیح خودکار متون، این تابع استاندارد پایتون پیاده‌سازی شده است:

```python
import re

def polish_persian(text: str) -> str:
    # 1. Unify Characters
    text = text.replace("ي", "ی").replace("ك", "ک")
    
    # 2. Eradicate all em/en dashes
    text = re.sub(r'[\u2014\u2013\u2015\u2012]', '، ', text)
    text = re.sub(r'--+', '، ', text)
    text = re.sub(r'\s+[-–—]\s*$', '', text, flags=re.MULTILINE)
    text = re.sub(r'^\s*[-–—]\s+', '', text, flags=re.MULTILINE)
    
    # 3. Quotes to Persian « »
    text = re.sub(r'["“]([^"”]*?)["”]', r'«\1»', text)
    
    # 4. Standardize ZWNJ
    text = re.sub(r'\bمی\s+', 'می\u200c', text)
    text = re.sub(r'\bنمی\s+', 'نمی\u200c', text)
    text = re.sub(r'\s+ها\b', '\u200cها', text)
    text = re.sub(r'\s+های\b', '\u200cهای', text)
    text = re.sub(r'\s+هایی\b', '\u200cهایی', text)
    text = re.sub(r'\s+تر\b', '\u200cتر', text)
    text = re.sub(r'\s+ترین\b', '\u200cترین', text)
    text = re.sub(r'\s+ام\b', '\u200cام', text)
    text = re.sub(r'\s+ات\b', '\u200cات', text)
    text = re.sub(r'\s+اش\b', '\u200cاش', text)
    text = re.sub(r'\s+مان\b', '\u200cمان', text)
    text = re.sub(r'\s+تان\b', '\u200cتان', text)
    text = re.sub(r'\s+شان\b', '\u200cشان', text)
    
    # 5. Punctuation Spacing
    text = re.sub(r'[ \t]+', ' ', text)
    text = re.sub(r'\s+([،؛:؟!.\)])', r'\1', text)
    text = re.sub(r'([\(\«])\s+', r'\1', text)
    
    return text.strip()
```

## ۸. چک‌لیست اعتبارسنجی نهایی (Verification Checklist)

- [ ] تمام «ي» و «ك» به حروف فارسی تبدیل شده‌اند.
- [ ] پیشوندهای «می‌/نمی‌» و پسوندهای «ها/تر/ترین/ضمایر» دارای نیم‌فاصله صحیح هستند.
- [ ] هیچ‌گونه خط‌تیره‌ای (`—` یا `–`) در ابتدا یا میانه دیالوگ‌ها وجود ندارد.
- [ ] تمام دیالوگ‌ها و نقل‌قول‌ها در گیومه فارسی (`«...»`) قرار دارند.
- [ ] علائم نگارشی بدون فاصله به کلمه قبل چسبیده و از کلمه بعد یک فاصله دارند.
- [ ] ترکیب‌های عطفی مانند `گفت‌وگو` و `جست‌وجو` با نیم‌فاصله و واو عطف ثبت شده‌اند.
- [ ] جملات از گرته‌برداری‌های مجهول و افعال حشو پالایش شده‌اند.
