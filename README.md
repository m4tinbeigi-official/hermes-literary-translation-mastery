## 📖 معرفی پروژه
این پروژه یک ابزار و خط لوله جامع برای **ترجمهٔ ادبی، شیوا و کامل هر نوع کتاب، رمان و مقاله** به زبان فارسی فاخر است.
با استفاده از این ابزار می‌توانید هر فایل متنی را بدون سانسور، بدون خلاصه‌سازی خودکار توسط مدل‌ها و با رعایت کامل سجاوندی اصیل فارسی و نیم‌فاصله‌ها به فارسی ترجمه کنید.

---

## 🎁 دریافت API رایگان از نارا روتر (Nara Router)
برای ترجمه کامل کتاب‌ها بدون نیاز به پرداخت هزینه، می‌توانید از روتر ایرانی **نارا** استفاده کنید:

1. وارد سایت [nara.sh](https://nara.sh) شوید و ثبت‌نام کنید.
2. از بخش داشبورد یا کلیدهای API، یک **API Key** بسازید.
3. کلید شما اعتبار رایگان برای مدل‌های قدرتمندی مثل `gemini-2.5-flash` و `gemini-3.7-flash` در اختیارتان می‌گذارد.

## 🚀 راهنمای سریع ترجمه هر کتاب

### ۱. نصب پیش‌نیازها
پروژه نیاز به کتابخانه خاصی ندارد و با پایتون استاندارد اجرا می‌شود:

```bash
git clone https://github.com/m4tinbeigi-official/hermes-literary-translation-mastery.git
cd hermes-literary-translation-mastery
```

### ۲. اجرای ترجمه روی فایل کتاب
کافیست فایل متن انگلیسی کتاب خود (`book.txt`) را در کنار اسکریپت بگذارید و دستور زیر را اجرا کنید:

```bash
# تنظیم کلید نارا روتر در ترمینال
export NARA_API_KEY="sk-nry-YOUR_NARA_KEY"

# اجرای ترجمه کتاب
python3 translate_book.py my_book.txt
```

یا مستقیماً با آرگومان:
```bash
python3 translate_book.py my_book.txt --api-key sk-nry-YOUR_NARA_KEY
```

## 💎 خروجی‌های تولید شده
پس از اتمام ترجمه، دو فایل در پوشه `output_translations` ساخته می‌شود:
1. **فایل Markdown (`*_persian.md`):** متن تمیز و مرتب ترجمه شده با رعایت گیومه «...» برای دیالوگ‌ها و حفظ نیم‌فاصله‌ها.
2. **کتابخوان وب (`*_persian.html`):** یک صفحه وب شکیل و خوانا با قلم زیبای وزیرمتن (Vazirmatn) که با باز کردن در مرورگر می‌توانید کتاب را مستقیماً مطالعه کنید.

## ⚡ ویژگی‌های فنی
- **سیستم ذخیره پیشرفت (Auto-Resume):** در صورت قطع اینترنت یا خروج، با اجرای مجدد، ادامه ترجمه از بخش متوقف‌شده انجام می‌شود.
- **قانون صفر خط‌تیره (Zero Em-Dash):** حذف ام‌دش‌های لاتین و جایگزینی با سجاوندی روان زبان فارسی.
- **تکه‌بندی هوشمند (Smart Chunking):** تفکیک پاراگراف‌ها برای جلوگیری از قطع شدن جملات و از دست رفتن پیوستگی متن.
