# شیوه‌نامهٔ نگارش، لحن و ویرایش (Style Guide)

این شیوه‌نامه، استانداردهای نگارش، دستور خط فارسی، نشانه‌گذاری و پروفایل لحن شخصیت‌ها را برای پروژه تعیین می‌کند.

---

## ۱. اصول دستور خط و نگارش فارسی

1. **نیم‌فاصله‌ها (Zero-Width Non-Joiner):**
   * در پیشوندها: `می‌شود`، `نمی‌تواند` (نه «می شود» یا «نمیتواند»).
   * در پسوندها: `کتاب‌ها`، `چوب‌دستی‌اش`، `دیده‌شده` (نه «کتابها» یا «چوب دستی اش»).
   * در صفات و ترکیبات: `سه‌سر`، `خون‌آلود`، `نامرئی‌ساز`، `سال‌اولی‌ها`.
2. **رسم‌الخط:**
   * استفاده از «ی» و «ک» استاندارد فارسی.
   * خودداری از نوشتن تنوین‌های نچسب؛ استفاده از شکل درست مانند «طبیعتاً»، «واقعاً».
3. **نشانه‌گذاری و نقل‌قول:**
   * گفتگوی مستقیم در دیالوگ‌ها با گیومهٔ فارسی (`«...»`).
   * **ممنوعیت مطلق خط تیره/ام‌دش:** استفاده از کاراکتر خط تیره (`—`) در تمام متن‌ها، توضیحات و دیالوگ‌ها اکیداً ممنوع است. به جای آن از ویرگول، پرانتز یا ساختار جمله‌بندی طبیعی فارسی استفاده شود.
   * هماهنگی پایان جملات در گیومه با ویرگول و نقطه.

## ۲. پروفایل لحن و صدای شخصیت‌ها (Voice Profiles)

| شخصیت | سطح رسمی بودن | سبک بیان و واژگان | ویژگی بارز |
| :--- | :--- | :--- | :--- |
| **دامبلدور** | رسمی / فاخر | شمرده، سرشار از آرامش، شوخ‌طبعی ظریف و خردمندانه | هرگز صدایش را بلند نمی‌کند؛ همیشه بر فضا مسلط است. |
| **مک‌گوناگال** | رسمی / دانشگاهی | خشک، قاطع، منضبط و بسیار مقید به قانون | سخت‌گیر اما به شدت عادل و مدافع شاگردانش. |
| **اسنیپ** | کتابی / سرد | برنده، کنایه‌آمیز، تهاجمی اما با صدایی آرام و نجوایی | استفاده از مکث‌های طولانی و تحقیر مؤدبانه. |
| **هاگرید** | محاوره‌ای / صمیمی | واژگان ساده، لحن احساسی، جملات گرم و خودمانی | وفاداری مطلق به دامبلدور، افشای ناخواستهٔ رازها. |
| **هرماینی** | کتابی / مشتاق | جملات بلند، پر از اطلاعات کتابخانه‌ای، سرعت بالا در بیان | در آغاز رئیس‌مآب و مقرراتی، اما وفادار و عمل‌گرا. |
| **ران** | غیررسمی / عامیانه | صریح، هیجانی، استفاده از تعجب‌ها و شوخی‌های نوجوانانه | واکنش‌های بدون فیلتر، ترس‌های بامزه (مثل ترس از عنکبوت). |
| **مالفوی** | اشرافی / نیش‌دار | کلمات مغرورانه، تحقیر افراد ضعیف‌تر، اتکا به جایگاه پدرش | کش‌دار صحبت کردن، توخالی بودن شجاعت در عمل. |
| **ورنون دورسلی** | عصبی / تحکم‌آمیز | پرخاشگر، داد و فریاد، لجاجت در برابر چیزهای غیرعادی | تکرار کلمات برای تاکید و ابراز انزجار. |
