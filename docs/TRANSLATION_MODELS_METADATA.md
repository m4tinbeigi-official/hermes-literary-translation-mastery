- **مدل:** `qwen2.5:3b-instruct` (کوآنتایز شده ۴ بیتی)
- **محیط اجرا:** CPU مک‌بوک (Intel Core i5, 8GB RAM)
- **میانگین زمان ترجمه هر چانک:** ۲۵ الی ۱۸۰ ثانیه
