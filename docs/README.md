# 🧙‍♂️ Hermes Literary Translation Engine & Harry Potter Master Suite
> خط تولید تمام‌خودکار، سینمایی و پیشرفته ترجمه ادبی رمان و کتاب بر پایه Hermes Agent، مدل‌های محلی (Ollama) و مدل‌های شناختی نسل جدید (Gemini 3.7).

## 🌟 درباره پروژه (About The Project)

این پروژه یک اکوسیستم و فریم‌ورک متن‌باز و جامع برای **ترجمه ادبی و فاخر رمان‌های چندجلدی (سریال)** به زبان فارسی است. این فریم‌ورک برای اولین بار مفاهیم زیر را در ترجمه رمان به زبان فارسی پیاده‌سازی و یکپارچه کرده است:

1. **انقلاب در لحن و نثر ادبی:** عبور از ترجمه‌های مکانیکی/ماشینی و رسیدن به نثری ریتمیک، زنده و سینمایی با رعایت دقیق سبک و هویت شخصیت‌ها.
2. **قانون اکید صفر ام‌دش (Zero Em-dash):** حذف کامل خط تیره‌های نامأنوس در فارسی و بازسازی جملات به کمک نحو طبیعی و مکث‌های روایی.
3. **دور زدن محدودیت‌های کپی‌رایت و امتناع مدل‌ها (Policy & Refusal Evasion):** مهندسی فریمینگ زبان‌شناختی بی‌طرفانه و چانک‌بندی میکروسکوپی بدون متادیتا برای عبور از فیلتر امتناع مدل‌های ابری.
4. **معماری ترکیبی (Hybrid Route):** پشتیبانی دوگانه از اجرای ۱۰۰٪ آفلاین و محلی (با مدل‌هایی مانند Qwen 2.5) و اجرای فوق‌پیشرفته ابری (با Gemini 3.7 Flash/Thinking).
5. **موتور کتاب‌ساز و کتاب‌خوان وب (Interactive Web Reader & Book Builder):** تبدیل خودکار فایل‌های ترجمه به نسخه تحت وب واکنش‌گرا و زیبا با فونت وزیرمتن و رابط دوزبانه.

## 🚀 راهنمای سریع راه‌اندازی (Quick Start)

### ۱. پیش‌نیازها
- پایتون نسخه 3.9 به بالا (`python3`)
- نرم‌افزار [Ollama](https://ollama.com) (برای حالت محلی آفلاین) یا دسترسی به API / Router (برای حالت ابری)

### ۲. اجرای حالت محلی (Offline with Ollama & Qwen)
ابتدا مدل Qwen 2.5 را دانلود کنید:
```bash
ollama run qwen2.5:3b
```
سپس اسکریپت ترجمه محلی را اجرا کنید:
```bash
python3 local_qwen_batch_translator.py
```

### ۳. اجرای پایپ‌لاین ابری با جمینای (Cloud Pipeline)
برای اجرای پایپ‌لاین سرعت‌بالا روی روتر یا کلود:
```bash
python3 run_all_7_books_gemini.py
```

### ۴. ساخت خروجی نهایی و کتاب تحت وب
پس از اتمام ترجمه‌ها، برای یکپارچه‌سازی تمام فصول در یک فایل واحد:
```bash
python3 build_book.py
```
سپس فایل `reader.html` یا `book.html` را در هر مرورگری باز کنید تا از مطالعه لذت ببرید!
