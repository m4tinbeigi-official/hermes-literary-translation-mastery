# واژه‌نامهٔ مرجع و تطبیقی (Glossary) - پروژه هری پاتر و سنگ جادو

این واژه‌نامه مرجع یکپارچه برای نام‌ها، مکان‌ها، اشیا، اصطلاحات، طلسم‌ها و ساختار داستان است تا در تمام تحلیل‌ها، یادداشت‌ها و بررسی‌ها هماهنگی کامل حفظ شود.

---

## ۱. شخصیت‌ها (Characters)

| نام انگلیسی | معادل فارسی مصوب | توضیحات و ریشه‌شناسی |
| :--- | :--- | :--- |
| **Harry Potter** | هری پاتر | قهرمان اصلی داستان؛ پسری که زنده ماند |
| **Albus Dumbledore** | آلبوس دامبلدور | مدیر مدرسه هاگوارتز؛ «آلبوس» به لاتین یعنی سفید، «دامبلدور» در انگلیسی کهن یعنی زنبور عسل بزرگ (Bumblebee) |
| **Minerva McGonagall** | مینروا مک‌گوناگال | معاون مدرسه و رئیس گریفیندور؛ «مینروا» الههٔ خرد و جنگ در روم باستان |
| **Severus Snape** | سوروس اسنیپ | استاد معجون‌سازی؛ «سوروس» یعنی سخت‌گیر/خشن؛ نام اسنیپ برگرفته از روستایی در انگلستان |
| **Rubeus Hagrid** | روبئوس هاگرید | کلیددار و شکاربان؛ «روبئوس» لاتین سرخ‌رنگ؛ «هاگرید» در گویش محلی یعنی شب‌زنده‌دار یا آشفته |
| **Hermione Granger** | هرماینی گرینجر | برگرفته از اساطیر یونان (هرمس) و نمایشنامهٔ شکسپیر؛ نماد هوش و مطالعه |
| **Ron Weasley** | ران ویزلی | دوست صمیمی هری؛ نماد وفاداری، از خانوادهٔ پرجمعیت ویزلی |
| **Draco Malfoy** | دراکو مالفوی | رقیب هری؛ «دراکو» یعنی اژدها/مار؛ «مالفوی» در فرانسوی کهن یعنی بدطینت/خیانت‌پیشه (Mal-foi) |
| **Lord Voldemort** | لرد ولدمورت | برگرفته از فرانسوی «Vol de mort» (پروازِ مرگ یا دزدیِ مرگ) |
| **Vernon Dursley** | ورنون دورسلی | شوهرخالهٔ هری؛ نماد روزمرگی و قشری‌گری طبقهٔ متوسط سنتی |
| **Petunia Dursley** | پتونیا دورسلی | خالهٔ هری؛ نام یک گل، نماد حسادت و کینهٔ سرکوب‌شده |
| **Dudley Dursley** | دادلی دورسلی | پسرخالهٔ لوس و قلدر هری |
| **Neville Longbottom** | نویل لانگ‌باتم | دانش‌آموز کم‌رو اما شجاع گریفیندور |
| **Quirinus Quirrell** | کویرینوس کوییرل | استاد دفاع در برابر جادوی سیاه؛ «کویرینوس» خدای دوجانبه در روم |
| **Garrick Ollivander** | گاریک اولیواندر | چوب‌دستی‌ساز معروف؛ خانواده‌ای که از ۳۸۲ پیش از میلاد فعال بوده‌اند |

## ۲. مکان‌ها و نهادها (Locations & Institutions)

| نام انگلیسی | معادل فارسی مصوب | مفهوم / کارکرد |
| :--- | :--- | :--- |
| **Hogwarts** | هاگوارتز | مدرسهٔ علوم و فنون جادوگری |
| **Diagon Alley** | کوچهٔ دیاگون | بازارچهٔ اصلی جادوگران در لندن (بازی با واژهٔ Diagonally) |
| **Knockturn Alley** | کوچهٔ ناکترن | بازارچهٔ ابزارهای تاریک و غیرقانونی (بازی با واژهٔ Nocturnally) |
| **Gringotts** | گرینگوتز | بانک جادوگری تحت ادارهٔ گابلین‌ها |
| **The Leaky Cauldron** | پاتیل درزدار | میخانه و مسافرخانهٔ رابط بین لندن عادی و دنیای جادو |
| **Privet Drive** | پریوت درایو | خیابان محل سکونت دورسلی‌ها |
| **Forbidden Forest** | جنگل ممنوعه | جنگل پرخطر و زیستگاه موجودات اسرارآمیز در مجاورت هاگوارتز |
| **Platform 9 ¾** | سکوی نه و سه‌چهارم | سکوی مخفی قطار در ایستگاه کینگزکراس |

## ۴. اصطلاحات جادویی و طلسم‌ها (Magic & Spells)

| اصطلاح / طلسم | معادل فارسی | توضیح |
| :--- | :--- | :--- |
| **Muggle** | ماگل | افراد فاقد قدرت جادویی |
| **Squib** | اسکوئیب | فرد فاقد جادو که از والدینی جادوگر متولد شده |
| **Philosopher's Stone** | سنگ جادو / سنگ کیمیا | ماده‌ای افسانه‌ای برای تبدیل فلزات به طلا و تولید اکسیر جاودانگی |
| **Alohomora** | آلوهومورا | طلسم باز کردن درها و قفل‌های معمولی |
| **Wingardium Leviosa** | وینگاردیوم لِویوسا | طلسم شناورسازی اشیا در هوا |
| **Petrificus Totalus** | پتریفیكوس توتالوس | طلسم خشک و بی‌حرکت کردن کامل بدن |
| **Lumos / Nox** | لوموس / ناکس | طلسم روشن / خاموش کردن نور سر چوب‌دستی |
| **Invisibility Cloak** | شنل نامرئی‌ساز | شنلی نایاب که فرد را کاملاً از دید پنهان می‌کند |
| **Sorting Hat** | کلاه گروه‌بندی | کلاهی باستانی برای ارزیابی ذهن و تعیین گروه دانش‌آموزان |
| **Mirror of Erised** | آینهٔ ایریزد | آینه‌ای که عمیق‌ترین تمنای قلبی فرد را نشان می‌دهد (Erised برعکس Desire) |

## ۵. ورزش کوییدیچ (Quidditch)

| اصطلاح | معادل فارسی | کارکرد در بازی |
| :--- | :--- | :--- |
| **Golden Snitch** | اسنیچ طلایی | گوی بالدار طلایی؛ صید آن ۱۵۰ امتیاز دارد و بازی را خاتمه می‌دهد |
| **Quaffle** | کوافل | توپ چرمی سرخ برای عبور دادن از ۳ حلقه و کسب ۱۰ امتیاز |
| **Bludger** | بلاجر | دو توپ سنگین آهنی مهاجم که بازیکنان را هدف قرار می‌دهند |
| **Seeker** | جستجوگر | بازیکنی که مسئول گرفتن اسنیچ است (نقش هری) |
| **Keeper** | دروازه‌بان | محافظت از ۳ حلقهٔ گل |
| **Chaser** | مهاجم | پاسکاری و پرتاب کوافل به درون حلقه‌ها |
| **Beater** | مدافع | مجهز به چماق‌های کوچک برای دفع بلاجرها از تیم خود |
